Single binary. Zero external daemons.

Deploy apps on a 1GB server without triggering the OOM killer

I like Coolify, but running PostgreSQL, Redis, Horizon, Traefik, and PHP-FPM just to host two small personal projects on a free Oracle instance is ridiculous. Bifrost puts the orchestrator, SQLite, TLS, and reverse proxy in a single 11MB binary that idles at 14MB of RAM.

The 1GB server tragedy

You get a free cloud VPS. You feel like a cloud architect. You decide to set up a self-hosted PaaS so you can push code like Vercel without paying \$20 a month.

You install the popular options. Five minutes in, your server stops responding. SSH hangs. You check the dashboard: the Linux OOM killer woke up in an absolute rage and murdered everything because the control plane alone ate 650MB of RAM.

Then you run npm build, and the remaining 350MB of RAM vanishes into Vite's multithreaded machinery. The machine reboots itself in shame.

Bifrost was built out of sheer irritation.

The Engineering Behind It

1. Remote Build Hack

GitHub gives you free 7GB runners. Why run webpack on your tiny cloud server? GitHub Actions builds your app remotely and pushes the artifact tarball to Bifrost. Server memory during build: 5MB.

2. Zero-Container Static Bypass

If you build a React or Vite site, why boot a Node container or Nginx instance? Bifrost serves the static assets directly with gzip streaming and SPA index.html routing. 0MB container overhead.

3. In-Process TLS & Proxy

Eliminates Traefik and Caddy. Uses Go's standard reverse proxy paired with sync.Pool 32KB buffer recycling and Let's Encrypt autocert. Lock-free atomic routing lookups.

4. Kiri Engine Support

Works with standard Docker, but supports Kiri (the lightweight Rust container engine). Instead of containerd's 150MB overhead, Kiri idles at 15MB.
